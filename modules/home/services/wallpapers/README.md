LEENIUM wallpaper image files (png, jpg, jpeg, webp, gif, bmp) live in this
directory. Every image here is a repository-owned built-in and is installed by
Home Manager to ~/.config/leenix/backgrounds/ on the next switch.

crowned.png is the canonical first-install default wallpaper: on a fresh
installation with no ~/.config/leenix/current/background, initialization points
the runtime pointer at ~/.config/leenix/backgrounds/crowned.png.
